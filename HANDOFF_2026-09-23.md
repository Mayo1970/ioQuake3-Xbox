## Suspects (all run before frame 1)

1. The script index: 471 KiB of C heap. The parser passed an off-console test
   with the real `pak0-8` scripts (1439 definitions, no crash or hang).
2. libjpeg (jpeg-9f): new code with its own heap use. `logo512.jpg` and
   `black.jpg` decode correctly during `Com_Init`.
3. The startup cinematics: `idlogo.RoQ` is queued on every boot (the command line has only
   `+set`), and `intro.RoQ` is queued when `com_introPlayed` is 0. `CL_PlayCinematic_f` decodes
   the first frame inside `Cbuf_Execute` of the first `Com_Frame` and
   allocates the 2.9 MiB RoQ decoder with `malloc`. Free RAM after `Com_Init` is 8 MiB.

## Facts already established

- nxdk `malloc` is dlmalloc on `VirtualAlloc` (no fixed heap limit).
- nxdk `getenv` returns NULL (safe for libjpeg).
- nxdk `lrintf` is an `assert(0)` stub; `Q_ftol` maps to `qftolsse` under `XBOX`.
- The NV2A needs a nonzero P field in `SET_TEXTURE_ADDRESS` and a convolution kernel in `SET_TEXTURE_FILTER`.
- 2D vertices go inline (`NV097_INLINE_ARRAY`), batched per shader.
- The asserts handler is `_xbox_assert` (one underscore); ours shows the debug screen and logs.
